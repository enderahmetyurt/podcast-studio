Made from one episode

Real output from Enderinko Podcast S2E6, the Turkish show this plugin was built for. Claude picked the moments, checked the cut points and wrote the titles. The scripts did the rest.

Turn the sound on: the captions follow the speech word by word.

What you get

Claude does the editorial work: what is worth clipping, where a sentence really starts, what makes a hook. Python and ffmpeg do the media work.

Show notes

Transcript, description in your own format, title ideas, chapters.

Final mix

Spoken intro over theme music, episode, outro. Loudness-normalized.

Clips

8-10 strongest moments, cut on clean sentence boundaries, captioned.

Launch montage

6-8 punchy quotes over music, intro card, end card. 4:5 and 9:16.

Post copy

Instagram, X, YouTube Shorts, TikTok, LinkedIn. Guest tagged.

Four commands

Or just say what you want ("make reels from this episode") and the right skill picks it up.

CommandWhat it doesOutput
/podcast-setupAsks about your show and writes its profile: language, links, colors, logo, music, description format.podcast.json
/podcast-episode rec.mp3 intro.m4aTranscribes, writes the description, suggests titles and chapters, mixes the final episode.description.md, final.mp3
/podcast-clips rec.mp3 cover.pngFinds moments, you pick, it renders captioned clips and writes copy for each platform.clips/*.mp4, clip-copy.md
/podcast-launch .Builds a launch-day montage from short quotes and writes copy, including LinkedIn.launch-4x5.mp4, launch-9x16.mp4

Your show, your style

Everything show-specific lives in one file. Point the setup skill at a past episode description and new ones come out in the same format.

// podcast.json
{
  "name": "My Show",
  "language": "en",
  "website": "myshow.fm",
  "socials": { "instagram": "@myshow", "x": "@myshow" },
  "brand": {
    "logo": "assets/logo.png",
    "colors": { "accent": "#FF40A0", "highlight": "#FFD60A" }
  },
  "audio": {
    "theme_music": "assets/theme.mp3",
    "outro": "assets/outro.mp3"
  },
  "description": { "template": "...", "footer": "..." }
}

Good to know

 

  • Any language Whisper supports. Transcripts, captions and copy follow your show's language.
  • Runs locally. mlx-whisper on Apple Silicon, faster-whisper on Linux and Windows. No upload service.
  • Needs Python 3.10+ and ffmpeg. The setup skill creates its own virtualenv.
  • No fonts or music bundled. Bring your own. Without a font, a bold system font is used.
  • It never posts for you. You get files and copy; uploading stays with you.
  • MIT licensed. Scripts work on their own too.
